**Notifications**: a bell that tells you what concerns you (assignments, @mentions, reminders before your
hourly tasks and runbook steps), plus an **Unassigned** row on Hourly Workload for work nobody owns yet.
Two database migrations (017, 018) run automatically on start; no configuration changes.

## Notifications

- **The bell** next to the logo shows how many are unread (also in the browser tab title, e.g. *(3) LajurOps*).
  Open it for a list grouped by Today / Yesterday / Earlier, with **All | Unread** and **Mark all read**;
  clicking one opens its task.
- **What you're told about:**

  | | |
  |---|---|
  | Assignment | You were assigned a task, or removed from one |
  | Changes to your work | Your task was rescheduled · a new comment on your task (or one you commented on) · you were **@mentioned** |
  | Dependencies | A task you're waiting for is done, so you can start |
  | Reminders | Your hourly task starts soon (15 min before) · your runbook step starts soon (10 min before) · a step's daily task is due today (09:00) |
  | Weekly Commitment | Monday 10:00: you haven't shared this week's commitment · you have overdue committed tasks |
  | Projects | All tasks in your project are done, so it's ready to close |

- **Never about your own changes**, and bursts are grouped: *Bob made 3 changes to APP-72* (with **Show changes**).
- **Your choice:** the gear in the panel switches each type on or off and sets how early reminders come
  (5 to 60 minutes). Reminders use your browser's time zone.
- **@mentions in comments:** type `@` to pick someone (↑/↓, Enter); mentions are highlighted, and only reach
  people who can see the workspace.
- Notifications are kept for 60 days. Reminders are checked every minute by the server and sent once each,
  even across restarts.

## Hourly Workload: Unassigned

- Tasks nobody owns get their own last row, **Unassigned · Needs an owner**, counted like a person's (overlapping
  hourly tasks once). Open it to see them and assign someone. The **Week grid** has an Unassigned row too, so
  you can see which time slots still need a person.
- Team totals and the grid's day totals still count only work people own. The CSV export includes the row.

## Also

- **One dropdown style everywhere:** the last browser-default dropdowns (reminder times, Daily/Hourly when adding
  a task in a project, and the workspace pickers on Hourly Workload, Weekly Commitment and the new-task dialog)
  now look and work like the app's other pickers.

## Fast with lots of notifications

Measured with 89,000 tasks, 218,000 runbook steps and 92,000 notifications (3,000 for one person):

| | Time |
|---|---|
| Unread count (each open tab checks every 30 s) | **5 ms** |
| Open the bell (latest 100) | **22 ms** |
| Change a task's status (now also notifies) | **15 ms**, as before |
| Comment with two @mentions | **10 ms** |
| Reminder check, every minute | **about 45 ms**; 89 ms in the busiest minute |
| 30 active people + 3,000 open tabs polling the bell | 240 requests/s, **0 errors**, bell p95 25 ms |

## API

New: `GET /api/notifications?tz=`, `GET /api/notifications/count`, `POST /api/notifications/read`,
`GET` / `PUT /api/notifications/settings`, and `GET /api/reports/workload/none/tasks` for unassigned tasks
(see the README). Workload rows have `unassigned: true` on the Unassigned row.
